# Telegram Web Client

Веб-клиент для управления Telegram через библиотеку Telethon и FastAPI.

## Описание

Этот проект демонстрирует интеграцию Telethon с FastAPI для создания веб-клиента для управления Telegram-аккаунтом. Вы можете:

- Просматривать диалоги и сообщения в удобном чат-интерфейсе
- Отправлять сообщения и файлы
- Отслеживать новые сообщения в реальном времени через toast-уведомления
- Автоматически отмечать сообщения как прочитанные при открытии диалога
- Выполнять рассылку сообщений
- Авторизоваться через веб-интерфейс без использования консоли

## Требования

- Python 3.8+
- Telegram аккаунт
- API ID и API Hash (получите на [my.telegram.org](https://my.telegram.org))

## Установка

1. **Клонируйте репозиторий или скачайте файлы проекта**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**

Создайте файл `.env` в корне проекта (на основе `.env.example`):

```env
API_ID=ваш_api_id
API_HASH=ваш_api_hash
SESSION_NAME=telegram_client  # Опционально, по умолчанию 'telegram_client'
```

**Как получить API ID и API Hash:**
- Перейдите на [my.telegram.org](https://my.telegram.org)
- Войдите в свой аккаунт
- Выберите "API development tools"
- Создайте новое приложение
- Скопируйте `api_id` и `api_hash`

## Запуск

1. **Запустите FastAPI приложение:**
```bash
python run.py
```
2. **Откройте браузер и перейдите по адресу:**
```
http://localhost:8000
```

3. **При первом запуске:**
   - Откроется окно авторизации в браузере
   - Введите номер телефона в формате +7XXXXXXXXXX (с кодом страны)
   - Введите код подтверждения из Telegram
   - Если у вас включена двухфакторная аутентификация, введите пароль
   - После успешной авторизации будет создан файл сессии (`.session`)
   - При следующих запусках авторизация произойдет автоматически

## Использование

### Веб-интерфейс

Откройте `http://localhost:8000` в браузере для доступа к веб-интерфейсу:

- **Список диалогов** (слева) - просмотр всех ваших чатов с количеством непрочитанных сообщений
- **Чат-интерфейс** (справа) - единый интерфейс для просмотра истории сообщений и отправки новых
  - История сообщений отображается в формате пузырей (как в Telegram)
  - Свои сообщения справа, чужие слева
  - Автоматическая прокрутка к последнему сообщению
  - Отправка сообщений через Enter или кнопку "Отправить"
- **Toast-уведомления** - всплывающие уведомления о новых сообщениях в реальном времени
  - Появляются в правом верхнем углу при получении нового сообщения
  - Автоматически исчезают через 5 секунд
  - Можно закрыть вручную - событие будет удалено из списка
- **Авторизация через веб** - полный цикл авторизации без использования консоли
  - Ввод номера телефона
  - Ввод кода подтверждения
  - Поддержка двухфакторной аутентификации
  - Возможность повторной отправки кода

### API Эндпоинты

#### Получить информацию о пользователе
```http
GET /api/me
```

#### Получить список диалогов
```http
GET /api/dialogs?limit=20
```

#### Получить сообщения из чата
```http
GET /api/chats/{chat_id}/messages?limit=20
```

#### Отметить сообщения как прочитанные
```http
POST /api/chats/{chat_id}/mark-read
```

#### Отправить сообщение
```http
POST /api/send-message
Content-Type: application/json

{
    "chat_id": "me",
    "message": "Привет из API!"
}
```

#### Отправить файл
```http
POST /api/send-file
Content-Type: multipart/form-data

chat_id: me
caption: Описание файла
file: [файл]
```

#### Рассылка сообщений
```http
POST /api/broadcast
Content-Type: application/json

{
    "message": "Рассылка",
    "chat_ids": ["chat1", "chat2", "chat3"]
}
```

#### Получить последние события
```http
GET /api/events
```

#### Удалить событие
```http
DELETE /api/events/{message_id}
```

#### Авторизация
```http
GET /api/auth-status              # Проверка статуса авторизации
POST /api/auth/send-code         # Отправить код подтверждения
POST /api/auth/sign-in           # Войти с кодом и паролем
GET /api/auth/needs-password     # Проверить необходимость пароля
POST /api/logout-telegram        # Выйти из аккаунта
```

#### Получить информацию о сущности
```http
GET /api/entity/{entity_id}
```

### Модули Telegram (`telegram/`)

**`client.py`** - Инициализация `TelegramClient`, экспортирует объект `client` для использования в других модулях.

**`handlers.py`** - Функция `setup_event_handlers()` для настройки обработчиков событий. Обработчики новых сообщений и отредактированных сообщений.

**`auth.py`** - Хранит состояние авторизации (`auth_state`) для многошаговой авторизации.

**`user.py`** - Функция `get_client_info()` для получения информации о текущем пользователе.

**`dialogs.py`** - Работа с диалогами:
- `get_dialogs()` - получение списка диалогов
- `mark_chat_as_read()` - отметка сообщений как прочитанных при открытии диалога

**`messages.py`** - Работа с сообщениями:
- `get_chat_messages()` - получение сообщений из чата
- `send_message_safe()` - безопасная отправка сообщений с валидацией
- `validate_entity()` - проверка существования чата/пользователя

**`events.py`** - Работа с событиями:
- `add_event()` - добавление события в список
- `get_recent_events()` - получение списка событий
- `remove_event()` - удаление события

### API Роутеры (`api/`)

**`auth.py`** - Авторизация:
- `GET /api/auth/status` - проверка статуса авторизации
- `POST /api/auth/send-code` - отправка кода подтверждения
- `POST /api/auth/sign-in` - вход с кодом и паролем
- `GET /api/auth/needs-password` - проверка необходимости пароля

**`dialogs.py`** - Диалоги:
- `GET /api/dialogs` - получение списка диалогов
- `POST /api/chats/{chat_id}/mark-read` - отметка сообщений как прочитанных

**`messages.py`** - Сообщения:
- `GET /api/chats/{chat_id}/messages` - получение сообщений
- `POST /api/send-message` - отправка сообщения (JSON)
- `POST /api/send-message-form` - отправка сообщения (Form)
- `POST /api/broadcast` - рассылка сообщений
- `GET /api/entity/{entity_id}` - информация о сущности

**`events.py`** - События:
- `GET /api/events` - получение событий
- `DELETE /api/events/{message_id}` - удаление события

**`files.py`** - Файлы:
- `POST /api/send-file` - отправка файла

**`user.py`** - Пользователь:
- `GET /api/me` - информация о текущем пользователе

**`logout.py`** - Выход:
- `POST /api/logout-telegram` - выход из аккаунта
